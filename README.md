# faanhuy.github.io

Source for my personal portfolio site, built with plain HTML/CSS/JS and hosted on GitHub Pages.

**Live:** https://faanhuy.github.io

## Stack

- No build step — static HTML, CSS, vanilla JS
- Light/dark theme (auto + manual toggle, persisted in `localStorage`)
- Deployed via GitHub Pages (branch: `main`, root)

## Structure

```
index.html
css/style.css
js/main.js
```
