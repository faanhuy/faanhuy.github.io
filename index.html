Enterprise DMS/ERP platform for FMCG/beverage distribution — territory management, warehouse, promotions, orders, KPIs and reporting. Team of 6–10 developers, each owning separate modules, multi-language product.

  • BackOffice module development — built and maintained core Purchase Order (PO) modules on ASP.NET MVC 4 / .NET Framework, with Ext.NET/ExtJS GridPanel UI and an EF Database-First (EDMX) backend over a custom stored-procedure data layer, covering the full PO lifecycle (create, close, delete, reporting) with price/tax lookups and Excel import/export.
  • External system integration — integrated the platform with WMS/logistics services and third-party promotion/rebate validation services via RestSharp/HTTP, mapping internal orders to partner payloads (SAP/DMS distributor codes, material, VAT) and reconciling responses.
  • Integration API (.NET 6) — built RESTful APIs to sync purchase orders, sales orders, delivery orders, inventory, and lot/pallet data with external partners, with dual authentication (JWT Bearer + Basic Auth), Dapper + EF Core across multiple SQL Server databases, and full request logging to DB.
  • Concurrency handling — designed a sequential request processor (concurrent queue + semaphore) to serialize simultaneous order-sync requests, preventing race conditions and duplicate processing under concurrent load.
  • SQL optimization — refactored legacy stored procedures through execution plan analysis and targeted indexing, significantly reducing query response times.
  • Background job processing — implemented Hangfire (.NET 6, SQL Server storage) for scheduled business automation: periodic data sync with an external ERP (authenticate → submit orders → log/retry) and automated Excel imports.
  • Enterprise patterns & observability — implemented audit trails, optimistic concurrency control, and multi-language support (4 languages); integrated AutoMapper, SMTP email (Office 365), Swagger/OpenAPI docs, and structured logging with Serilog + Seq.
  • Production support — resolved incidents for enterprise clients including ABInBev, Nabati, Sabeco and Anvy via the support team: business logic bugs, performance issues, API sync failures, and change requests, with direct client communication on integration requirements.
